# Data

- `raw/` — Downloaded benchmarks (Ortho2CAD, DeepCAD, Fusion 360) + real company drawings
- `processed/` — Normalized CDR JSON, preprocessed raster images
- `synthetic/` — Generated multimodal dataset (PNG, DXF, SVG, PDF from ground-truth STEP)

See `docs/roadmap/implementation-roadmap.md` Phase 14 and `docs/benchmarks/benchmark-evaluation-plan.md` Sections 13-14 for split strategy.
